# pf_kektura
Kéktúrázást segítő webalkalmazás, mely kölönböző tömegközlekiedési információkkal segíti a kéktúrázást.

Az alkalmazás képes letölteni a következő adatforrásokat és ezekből csinál adatbázist, melyre a térképes app épülít fel.


Volánbusz Zrt. adatok: https://gtfs.kti.hu/public-gtfs/volanbusz_gtfs.zip
